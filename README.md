## 法兰克福这个位置值多少

法兰克福是 DE-CIX 的所在地，德国、奥地利、瑞士（DACH）以及波兰、捷克这些中东欧市场，从法兰克福出去的延迟最低。Cloudzy 在自己的德国页面上写，法兰克福到 DACH 和大部分欧洲地区的 P50 中位延迟低于 10ms。这是厂商自述，没有第三方测量数据支撑，当参考看。

数据驻留是另一个理由。德国是欧盟成员国，机器、磁盘、备份放在法兰克福，就满足了"数据留在 EU"的基础条件。Wolkra 明确写它的磁盘、备份和快照都存在法兰克福机房。

但"数据在 EU"不等于"GDPR 合规"。Cloudzy 的 FAQ 把这件事说得很直白：合规取决于你的应用架构、处理者协议和你处理的数据，基础设施只是提供可能性，DPA 要单独谈。HostFinch 的表述一样，完整合规还取决于应用怎么处理个人数据。日志留存多久、备份放在哪、页面里嵌了哪些第三方统计脚本，都在审查范围内。买一台德国 VPS 只完成了第一步。

## 标价不等于月付：三个加项

这是德国 VPS 最容易算错的地方。以 Wolkra 为例，S0 套餐页面标 €3.49/月，IPv4 地址另收 €0.89/月，备份按服务器价格的 20% 收，约 €0.70。三项加总 €5.08/月，还不含 VAT。页面上的 €3.49 从来没包含过这三样。

按这个思路检查你要买的机器，加项通常在这几处：

- **IPv4**：有的商家含 1 个，有的单独收费。Wolkra 是 €0.89/月，HostFinch 的额外 IPv4 是 $5/月，接近它入门套餐价格的一半。
- **备份**：OVHcloud 四个套餐都含前 24 小时的每日备份；Wolkra 收服务器价的 20%；MainHoster 是自助备份，不额外收费。
- **控制面板许可**：HostFinch 的 cPanel 加 Nginx 是 $69.99/月，LiteSpeed 许可 $38.99 到 $88.99/月，比多数套餐本身还贵。装宝塔或者用免费的 LEMP 栈就没这笔钱。
- **VAT**：Wolkra 的报价明确不含 VAT。欧盟以外的个人用户通常不涉及，公司采购要看清楚。

## KVM 和 LXC：装 Docker 之前要搞清楚的事

德国几家低价商家的虚拟化类型并不统一。MainHoster 全系 LXC 容器，OVHcloud、Cloudzy、Wolkra 标 KVM，LightLayer 在第三方目录里记为 KVM。

LXC 共享宿主内核，开销小，同价位能拿到更多 CPU 和内存。代价是写死的：不能自己编译内核，不能加载自定义内核模块，不能在容器里再跑一台 KVM。MainHoster 自己在页面上写明，需要独立内核或嵌套虚拟化就该选 KVM 产品。

这件事的实际影响比想象中大。装 Docker 本身在 LXC 里能跑，一旦碰到依赖特定内核模块的软件，比如某些 VPN 实现、文件系统工具、eBPF 相关的监控 agent，就会卡住。想在 VPS 里再开虚拟机做测试环境，LXC 直接出局。

LightLayer 标的是 KVM，独立内核这条需求能满足。第三方目录的标注不等于官方承诺，下单前在页面上确认一次更稳妥。

## "不限流量"有四种写法

德国 VPS 页面上的流量条款，至少要分清四种。

**硬配额。** LightLayer 德国节点写的是 1TB/月，超出怎么计费，公开资料没说明，得问。

**非计量但保留干预权。** Wolkra 和 MainHoster 都是这种，页面写 unmetered，同时保留对造成异常负载的服务器限速的权利。MainHoster 说得更具体：可以当 VPN 接入点，但不接受常驻隧道，不接受全天候把全部流量绕经 VPS，不接受当下载或流媒体网关，还举了个例子，几天内跑 100GB 下载会主动联系用户。

**分区域的不限量。** OVHcloud 四个套餐都写无限流量，脚注排除亚太机房：孟买、新加坡、悉尼的 VPS-1 有 500GB 月配额，VPS-2 和 VPS-3 是 1TB，VPS-4 是 3TB，超额限速 10Mbps。

**端口限速代替流量计费。** 端口给 300Mbps 或者 1Gbps，不看总量看瞬时速率。

同样是"unmetered"，背后是三套完全不同的规则。买之前把自己每月大概跑多少 GB 估一遍再对照条款，比看宣传语有用。

## 下单前的确认清单

- 虚拟化类型是 KVM 还是 LXC，能不能加载你要用的内核模块。
- IPv4 含不含，额外 IP 多少钱一个月。
- 备份是免费、自助，还是按比例收费。
- 流量是硬配额还是 fair use，超额怎么处理。
- 计费周期是月付、年付还是按小时，续费价和首期价是否一致。
